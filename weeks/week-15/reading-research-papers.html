Lesson 15.4: Reading ML Research Papers

How to Read an ML Paper

Reading research papers efficiently is a learnable skill. A 12-page NeurIPS paper can be read in 3 passes of decreasing time investment: first a 5-minute skim for relevance, then a 30-minute read for understanding the contribution, then a deep read to evaluate and reproduce results. Most practitioners never need the third pass for most papers.

The Three-Pass Method

# Pass 1: 5 minutes — should I read this?
pass_1 = {
    "read": ["Title", "Abstract", "Introduction (first paragraph)",
             "Section headings", "Conclusion", "One figure"],
    "answer": "What problem? What claimed contribution? Is it relevant to me?"
}

# Pass 2: 30-60 minutes — do I understand the contribution?
pass_2 = {
    "read": ["Full paper (skip proofs and implementation details)"],
    "annotate": ["Key claims", "Main figures and tables", "References to follow"],
    "answer": "What exactly did they do? Does the evidence support the claims?"
}

# Pass 3: 2-4 hours — can I reproduce it?
pass_3 = {
    "read": ["Full paper including proofs and appendices"],
    "do":   ["Reproduce key experiments or proofs", "Check code if available"],
    "answer": "Are the claims correct? What are the limitations? What's missing?"
}

Anatomy of an ML Paper

SectionWhat to extractRed flags
AbstractCore claim + metric claimedNo comparison baseline stated
Related WorkPositioning vs prior artMissing key related papers
MethodNovel contribution; reproducibilityVague descriptions; no equations
ExperimentsDatasets; baselines; ablationsWeak baselines; no error bars; cherry-picked results
ResultsMain table; statistical significanceNo significance tests; results on training set
LimitationsWhat the method doesn't doAbsent limitations section

Evaluating Claims Critically

# Questions to ask about any empirical claim

questions = [
    "Is the baseline strong? (recent, tuned, using the same budget?)",
    "Is the dataset the same split/version as prior work?",
    "Are error bars or confidence intervals reported?",
    "Is the claimed improvement statistically significant?",
    "Does the method have more parameters/compute than the baseline?",
    "Are results on held-out test data, or validation data?",
    "Is there an ablation study isolating each contribution?",
    "Is code available? Do results reproduce?",
    "Would the method work on my problem, or is it dataset-specific?",
]

# Essential landmark papers to read for each area:
landmark_papers = {
    "Deep Learning":        ["Krizhevsky 2012 (AlexNet)", "Goodfellow 2014 (GAN)", "He 2016 (ResNet)"],
    "NLP":                  ["Vaswani 2017 (Transformer)", "Devlin 2018 (BERT)", "Brown 2020 (GPT-3)"],
    "Optimisation":         ["Kingma 2014 (Adam)", "Loshchilov 2019 (AdamW)"],
    "Regularisation":       ["Srivastava 2014 (Dropout)", "Ioffe 2015 (BatchNorm)"],
    "Self-supervised":      ["He 2020 (MoCo)", "Chen 2020 (SimCLR)", "He 2022 (MAE)"],
    "Generative":           ["Kingma 2013 (VAE)", "Ho 2020 (DDPM)"],
}

for area, papers in landmark_papers.items():
    print(f"\n{area}:")
    for p in papers: print(f"  - {p}")
