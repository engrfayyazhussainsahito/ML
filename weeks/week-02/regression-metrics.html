Lesson 2.4: Regression Metrics

Why Metrics Matter

The choice of evaluation metric directly shapes what a model learns. A model trained to minimise MSE will trade many small errors for fewer large errors; a model minimising MAE is more robust to outliers. Choosing the wrong metric produces models that are technically good on paper but wrong for the application.

Mean Squared Error (MSE) and RMSE

MSE = (1/n) Σ(yᵢ - ŷᵢ)². It penalises large errors quadratically. RMSE = √MSE brings the metric back to the units of y, making it interpretable.

import numpy as np
from sklearn.metrics import mean_squared_error

y_true = np.array([3.0, -0.5, 2.0, 7.0, 4.5])
y_pred = np.array([2.5,  0.0, 2.1, 6.2, 4.8])

mse  = mean_squared_error(y_true, y_pred)
rmse = np.sqrt(mse)
print(f"MSE:  {mse:.4f}")
print(f"RMSE: {rmse:.4f}")   # same units as y

# Manual: verify the formula
manual_mse = ((y_true - y_pred)**2).mean()
assert abs(mse - manual_mse) < 1e-10
RMSE is the most common regression metric in ML competitions (Kaggle, etc.). But it is sensitive to outliers — a single large error can dominate the metric.

Mean Absolute Error (MAE)

MAE = (1/n) Σ|yᵢ - ŷᵢ|. It penalises all errors equally regardless of magnitude. MAE is more robust to outliers than MSE and is easier to interpret — it is the average absolute prediction error in units of y.

from sklearn.metrics import mean_absolute_error

mae = mean_absolute_error(y_true, y_pred)
print(f"MAE: {mae:.4f}")   # average |error| in y's units

R² (Coefficient of Determination)

R² = 1 - SS_res/SS_tot where SS_res = Σ(y-ŷ)² and SS_tot = Σ(y-ȳ)². It measures the proportion of variance in y explained by the model. R²=1 is perfect; R²=0 means the model is no better than predicting the mean; R²<0 is possible (model worse than mean).

from sklearn.metrics import r2_score
import numpy as np

r2 = r2_score(y_true, y_pred)
print(f"R²: {r2:.4f}")

# Adjusted R² — penalises adding useless features
n, p = 1000, 10
adj_r2 = 1 - (1 - r2) * (n - 1) / (n - p - 1)
print(f"Adjusted R²: {adj_r2:.4f}")

# Warning: R² is not comparable across datasets with different y variances
# A low-variance dataset can give high R² even for a poor model

Mean Absolute Percentage Error (MAPE)

import numpy as np

def mape(y_true, y_pred, eps=1e-10):
    """MAPE — expresses error as % of true value. Undefined when y_true=0."""
    return np.mean(np.abs((y_true - y_pred) / (np.abs(y_true) + eps))) * 100

y_true_pos = np.array([100, 200, 150, 300])
y_pred_pos = np.array([110, 190, 160, 280])
print(f"MAPE: {mape(y_true_pos, y_pred_pos):.1f}%")

# Symmetric MAPE (sMAPE): avoids asymmetry and division-by-zero issues
def smape(y_true, y_pred):
    return 200 * np.mean(
        np.abs(y_pred - y_true) / (np.abs(y_true) + np.abs(y_pred) + 1e-10))

Choosing the Right Metric

MetricUse whenSensitive to outliers?
RMSELarge errors are especially costlyYes (quadratic penalty)
MAEAll errors equally important; outliers presentNo
R²Comparing models on the same datasetModerately
MAPERelative error matters (e.g. forecasting)No, but undefined at zero
HuberRobustness needed; outliers but some toleranceConfigurable via epsilon
