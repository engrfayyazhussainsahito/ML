Lesson 1.1: Defining ML & AI

What is Machine Learning?

Machine learning is a subfield of artificial intelligence in which a system learns to perform a task by finding patterns in data, rather than being given explicit rules by a programmer. The learning happens by optimising a mathematical objective — a loss function — using examples.

A more precise definition, due to Tom Mitchell (1997):

"A computer program is said to learn from experience E with respect to some task T and performance measure P, if its performance at tasks in T, as measured by P, improves with experience E."
The critical insight: in ML, the programmer writes the learning algorithm, not the task-solving algorithm. The task-solving algorithm is discovered from data.

ML vs Classical Programming

In classical software engineering, a programmer encodes explicit rules: if temperature > 38 then flag_fever = True. The rules must be written by hand, which fails when the rules are too complex, too numerous, or unknown.

In machine learning, you provide inputs (features) and desired outputs (labels), and the algorithm discovers the mapping automatically.

ML vs Statistics

ML and statistics share deep roots but differ in emphasis. Statistics traditionally focuses on inference — understanding the data-generating process, quantifying uncertainty, and testing hypotheses. ML focuses on prediction — building models that generalise to new data. In practice the boundary is blurry and practitioners draw on both traditions.

Where ML Excels

ML is most powerful when: the problem is too complex to hand-code rules; large labelled datasets exist; the input is high-dimensional (images, audio, text); or when the optimal solution changes over time and the model can be retrained.

  • Image recognition — identifying objects, faces, medical pathology
  • Natural language processing — translation, summarisation, question answering
  • Recommendation systems — predicting user preferences at scale
  • Anomaly detection — fraud, network intrusion, equipment failure
  • Scientific discovery — protein folding, drug candidate screening

The Three Learning Paradigms

Almost all ML algorithms fall into one of three paradigms, each defined by the type of feedback the learner receives:

Supervised

Learn from labelled examples (input–output pairs). The model minimises error on known labels and generalises to new inputs. Examples: classification, regression.

Unsupervised

Find structure in unlabelled data. No correct answer is provided — the model discovers clusters, dimensions, or density. Examples: clustering, PCA, generative models.

Reinforcement

An agent learns by interacting with an environment and receiving reward signals. The goal is to maximise cumulative reward over time. Examples: game playing, robotics.

A Minimal ML Example in Python

from sklearn.linear_model import LinearRegression
import numpy as np

# Training data: house size (sq ft) → price ($k)
X_train = np.array([[500], [750], [1000], [1250], [1500]])
y_train = np.array([150, 200, 260, 310, 380])

# Train a linear regression model
model = LinearRegression()
model.fit(X_train, y_train)

# Predict on new data
X_new = np.array([[900], [1100]])
predictions = model.predict(X_new)
print(predictions)  # [238.4, 282.6]

# The model learned: price ≈ 0.228 × size + 36.6
print(f"Slope: {model.coef_[0]:.3f}, Intercept: {model.intercept_:.1f}")

In eight lines we have: loaded data, trained a model, and made predictions on unseen inputs. The fit() call ran an optimisation algorithm (ordinary least squares) that found the best line through the training points. The predict() call applied that line to new inputs.
