Lesson 14.1: Bias, Fairness & Accountability

Why Fairness is a Technical Requirement

When an ML model is deployed in consequential settings — loan approval, medical diagnosis, hiring, criminal sentencing — systematic errors with respect to protected characteristics (race, gender, age, disability) constitute both ethical and legal failures. Fairness is not a post-hoc consideration; it must be built into the ML workflow from data collection through deployment.

A model achieving 95% overall accuracy can simultaneously be dramatically worse for minority subgroups. Overall metrics hide demographic disparities — always disaggregate your evaluation metrics.

Fairness Metrics

There is no single universal definition of fairness. Different definitions are mathematically incompatible — you must choose based on the context and stakeholders.

import numpy as np

def fairness_report(y_true, y_pred, group):
    """
    Compute group-level fairness metrics.
    y_true, y_pred: binary arrays
    group: binary array indicating group membership (0 or 1)
    """
    for g in [0, 1]:
        mask = group == g
        tp = ((y_pred == 1) & (y_true == 1) & mask).sum()
        fp = ((y_pred == 1) & (y_true == 0) & mask).sum()
        fn = ((y_pred == 0) & (y_true == 1) & mask).sum()
        tn = ((y_pred == 0) & (y_true == 0) & mask).sum()

        precision = tp / (tp + fp + 1e-9)
        recall    = tp / (tp + fn + 1e-9)
        fpr       = fp / (fp + tn + 1e-9)   # false positive rate

        pos_rate  = y_pred[mask].mean()   # demographic parity metric

        print(f"Group {g}: precision={precision:.3f}, recall={recall:.3f}, "
              f"FPR={fpr:.3f}, positive rate={pos_rate:.3f}")

# Demographic parity: pos_rate should be equal across groups
# Equalised odds:     both TPR and FPR should be equal across groups
# Predictive parity:  precision should be equal across groups

Mitigation Strategies

Pre-processing

Resampling, reweighting, or transforming data before training. Addresses historical bias at the source.

In-processing

Adding fairness constraints or regularisation terms to the training objective. Directly optimises for fairness.

Post-processing

Adjusting decision thresholds per group after training. Simple but can reduce overall accuracy.
