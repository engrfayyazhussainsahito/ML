Lesson 0.3: Linear Algebra Essentials

Linear Algebra as the Language of ML

Every ML model you will ever build operates on vectors and matrices. A dataset of n examples with p features is a matrix X of shape (n, p). Model weights are vectors. Predictions are matrix multiplications. Backpropagation uses the Jacobian. Knowing linear algebra lets you read ML papers and debug tensor shape errors.

Vectors

import numpy as np

# A vector: an ordered list of scalars
v = np.array([1.0, 2.0, 3.0])   # shape (3,)

# L2 norm (Euclidean length): ||v|| = sqrt(v·v)
print(np.linalg.norm(v))         # 3.742

# Dot product: v·w = Σ vᵢwᵢ
w = np.array([4.0, 5.0, 6.0])
print(np.dot(v, w))              # 32.0

# Cosine similarity — measures angle between vectors
cos_sim = np.dot(v, w) / (np.linalg.norm(v) * np.linalg.norm(w))
print(cos_sim)                   # 0.9746 (very similar directions)

Matrices

# Matrix: shape (rows, columns)
A = np.array([[1, 2], [3, 4], [5, 6]])   # shape (3, 2)
B = np.array([[7, 8, 9], [10, 11, 12]])  # shape (2, 3)

# Matrix multiplication: (3,2) @ (2,3) → (3,3)
C = A @ B
print(C.shape)     # (3, 3)

# Transpose: swap rows and columns
print(A.T.shape)   # (2, 3)

# Identity and inverse
I = np.eye(3)
M = np.array([[2,1],[5,3]])
M_inv = np.linalg.inv(M)
print(M @ M_inv)   # ≈ identity matrix

Eigenvalues and Eigenvectors

An eigenvector v of matrix A satisfies: Av = λv, where λ is the corresponding eigenvalue. Eigenvectors point in directions that A only stretches (or flips), not rotates. PCA relies entirely on eigendecomposition.

A = np.array([[3, 1], [0, 2]])
eigenvalues, eigenvectors = np.linalg.eig(A)
print("Eigenvalues:", eigenvalues)        # [3., 2.]
print("Eigenvectors:\n", eigenvectors)

Broadcasting

NumPy broadcasting allows arithmetic on arrays of different shapes without explicit loops:

X = np.random.randn(1000, 10)   # 1000 samples, 10 features

# Feature normalisation: subtract mean, divide by std
# Without broadcasting: would need a loop
mean = X.mean(axis=0)    # shape (10,)
std  = X.std(axis=0)     # shape (10,)

X_norm = (X - mean) / std   # broadcasts over 1000 rows — shape (1000, 10)
