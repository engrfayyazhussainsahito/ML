Lesson 1.2: Learning Paradigms

The Three Paradigms

Almost every ML algorithm belongs to one of three learning paradigms, defined by the type of signal the learner receives during training.

graph TD
  A[Learning Paradigm] --> B[Supervised]
  A --> C[Unsupervised]

  B --> B2[Regression]
  C --> C1[Clustering]
  C --> C2[Dim. Reduction]

  D --> D2[Robotics]

Supervised Learning

The learner receives a dataset of (input, label) pairs D = {(x₁,y₁), …, (xₙ,yₙ)} and learns a function f: X→Y that minimises prediction error on unseen data. The core assumption: training and test data are drawn i.i.d. from the same distribution.

from sklearn.datasets import make_classification
from sklearn.ensemble import RandomForestClassifier
from sklearn.model_selection import train_test_split
from sklearn.metrics import classification_report
import numpy as np

X, y = make_classification(n_samples=1000, n_features=20,
                            n_informative=10, n_classes=3,
                            random_state=42)

X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.2, stratify=y, random_state=42)

model = RandomForestClassifier(n_estimators=100, random_state=42)
model.fit(X_train, y_train)
print(classification_report(y_test, model.predict(X_test)))

Unsupervised Learning

No labels are provided. The learner must discover structure — clusters, latent factors, density — from P(x) alone. Evaluation is harder because there is no ground-truth to compare against.

from sklearn.cluster import KMeans
from sklearn.decomposition import PCA
from sklearn.preprocessing import StandardScaler
import numpy as np

X = np.random.randn(500, 20)

# 1. Reduce to 2D for visualisation
X_2d = PCA(n_components=2).fit_transform(StandardScaler().fit_transform(X))

# 2. Cluster in 2D
km = KMeans(n_clusters=4, random_state=42, n_init=10)
km.fit(X_2d)
print("Cluster sizes:", np.bincount(km.labels_))

# Inertia: sum of squared distances to cluster centres
print(f"Inertia: {km.inertia_:.1f}")

Semi-Supervised Learning

Most real-world datasets have abundant unlabelled data and scarce labels. Semi-supervised methods use both: labels for supervision and unlabelled data to regularise representations via consistency constraints or pseudo-labelling.

from sklearn.semi_supervised import LabelSpreading
import numpy as np

# -1 signals "unlabelled" to sklearn's semi-supervised estimators
y_semi = y_train.copy()
y_semi[100:] = -1   # only first 100 are labelled

ls = LabelSpreading(kernel='rbf', alpha=0.2, max_iter=1000)
ls.fit(X_train, y_semi)
print(f"Semi-supervised accuracy: {ls.score(X_test, y_test):.3f}")

Reinforcement Learning

An agent interacts with an environment, taking actions that change state and yield rewards. The goal is a policy π(a|s) that maximises expected cumulative reward (return G = Σ γᵗ rₜ, where γ is a discount factor).

import gymnasium as gym

env = gym.make("CartPole-v1")
obs, _ = env.reset(seed=42)
total_reward, done = 0, False

while not done:
    action = env.action_space.sample()   # random policy
    obs, reward, terminated, truncated, _ = env.step(action)
    total_reward += reward
    done = terminated or truncated

print(f"Total reward (random): {total_reward}")
# A trained agent achieves ~500 (max). Random: ~20.
