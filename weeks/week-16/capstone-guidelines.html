Lesson 16.1: Capstone Project Guidelines

Capstone Project Overview

The capstone is a self-directed end-to-end ML project demonstrating mastery of the full pipeline: problem framing, data collection, EDA, feature engineering, model development, evaluation, and communication. It is the centrepiece of your portfolio and the primary evidence of graduate-level competence you will present to employers and research programmes.

Project Scope Guidelines

DimensionMinimumStrongExceptional
Problem typeClassification or regression on a public datasetNovel dataset you collected or curatedMulti-modal or multi-task problem
Data size>1000 samples>10k samples with cleaning challengesMillion+ samples with engineering
Models2+ baselines + 1 strong modelSystematic comparison + ablationNovel architecture or training procedure
EvaluationTrain/val/test split, 2+ metricsCross-validation, confidence intervalsHuman evaluation or real deployment
CodeWorking notebookModular Python package with testsProduction-ready with CI/CD
DocumentationREADMEREADME + model card + reportPublished paper or technical blog

Project Timeline

timeline = {
    "Week 1: Scoping": [
        "Choose domain and problem type",
        "Survey existing solutions (literature review)",
        "Identify data sources",
        "Define success metric and baseline",
        "Write project proposal (1 page)"
    ],
    "Week 2: Data": [
        "Collect/download dataset",
        "Perform EDA on training split only",
        "Document data quality issues",
        "Write dataset description (data card)"
    ],
    "Week 3-4: Modelling": [
        "Implement preprocessing pipeline",
        "Train baseline models",
        "Iterative improvement with CV",
        "Hyperparameter optimisation",
        "Error analysis — what does the model get wrong?"
    ],
    "Week 5: Evaluation and Write-up": [
        "Final evaluation on test set (once!)",
        "Statistical significance testing",
        "Write project report",
        "Prepare defence presentation",
        "Clean and document code"
    ]
}

for phase, tasks in timeline.items():
    print(f"\n{phase}")
    for task in tasks: print(f"  - {task}")

Selecting a Problem

evaluation_criteria = {
    "Novelty":      "Is this problem genuinely open, or solved by existing tools?",
    "Impact":       "Would a good solution matter to real people?",
    "Feasibility":  "Can you get sufficient data? Is compute available?",
    "Differentiability": "Does this showcase skills others might not have?",
    "Interest":     "Will you stay motivated for 5 weeks?"
}

good_project_ideas = [
    "Predict medical readmission from EHR data (tabular + temporal)",
    "Low-resource NMT for an underrepresented language pair",
    "Real-time sign language recognition from webcam",
    "Predicting software bug severity from commit messages + diffs",
    "Multi-label scientific article classification across 100+ categories",
    "Energy consumption forecasting with external weather features",
    "Satellite image segmentation for deforestation monitoring",
]
