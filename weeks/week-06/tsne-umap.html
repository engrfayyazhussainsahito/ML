Lesson 6.4: t-SNE and UMAP

Non-Linear Dimensionality Reduction

PCA is linear — it cannot capture curved manifolds. t-SNE and UMAP are non-linear methods designed for 2D/3D visualisation. They preserve local neighbourhood structure, revealing clusters that PCA misses. However, they are not suitable for preprocessing before classification — distances in t-SNE/UMAP space are not globally meaningful.

t-SNE: t-Distributed Stochastic Neighbour Embedding

from sklearn.manifold import TSNE
from sklearn.datasets import load_digits
from sklearn.preprocessing import StandardScaler
import numpy as np

digits = load_digits()
X, y = digits.data, digits.target   # 1797 samples, 64 features, 10 classes

X_scaled = StandardScaler().fit_transform(X)

# For large datasets: first reduce with PCA, then t-SNE
from sklearn.decomposition import PCA
X_pca50 = PCA(n_components=50).fit_transform(X_scaled)

tsne = TSNE(
    n_components=2,
    perplexity=30,       # ~number of effective nearest neighbours (5-50)
    learning_rate='auto',
    n_iter=1000,
    random_state=42,
    init='pca'           # pca init is more stable than random
)
X_2d = tsne.fit_transform(X_pca50)
print(f"t-SNE output shape: {X_2d.shape}")   # (1797, 2)
print(f"KL divergence: {tsne.kl_divergence_:.4f}")  # lower = better

# Clusters in X_2d correspond to digit classes if separation is good

UMAP: Uniform Manifold Approximation and Projection

UMAP (McInnes et al., 2018) is faster than t-SNE, scales to millions of points, and preserves more global structure. It is built on Riemannian geometry and topological data analysis. Unlike t-SNE, UMAP can be used for out-of-sample transformation.

import umap   # pip install umap-learn
import numpy as np

reducer = umap.UMAP(
    n_neighbors=15,       # local neighbourhood size (like t-SNE perplexity)
    min_dist=0.1,         # how tightly to pack points in low-dim space
    n_components=2,
    metric='euclidean',
    random_state=42
)
X_umap = reducer.fit_transform(X_pca50)
print(f"UMAP output shape: {X_umap.shape}")

# Out-of-sample transform (t-SNE cannot do this)
X_new = np.random.randn(10, 50)
X_new_umap = reducer.transform(X_new)   # works!

Practical Guidelines

t-SNEUMAP
SpeedSlow (O(n log n))Fast (O(n^1.14))
Global structurePoorBetter
Out-of-sampleNoYes
Hyperparametersperplexityn_neighbors, min_dist
Reproducibilityrandom_state requiredrandom_state required
Best forDense cluster visualisationGeneral purpose, large datasets
Do not use t-SNE or UMAP embeddings as input features to a classifier — cluster distances are not globally consistent. Use PCA or autoencoders for that purpose.
