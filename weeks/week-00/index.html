Week 0 · Python & Maths Primer

Before writing a single ML model, you need fluency in the tools and mathematics that underpin the entire field. This week covers Python essentials for data science, NumPy array operations, the linear algebra and calculus you will use every week, and the probability and statistics that make learning from data meaningful.

Lessons This Week

Lesson 0.1

Python for ML

Data types, functions, classes, list comprehensions, and setting up a Jupyter environment.

Lesson 0.2

NumPy & Arrays

ndarrays, broadcasting, vectorisation, and the operations that replace slow Python loops.

Lesson 0.3

Linear Algebra Essentials

Vectors, matrices, dot products, matrix multiplication, and eigendecomposition.

Lesson 0.4

Calculus & Gradients

Derivatives, partial derivatives, the chain rule, and the gradient — the engine of learning.

Lesson 0.5

Probability & Statistics

Distributions, Bayes theorem, expectation, variance, and maximum likelihood estimation.
