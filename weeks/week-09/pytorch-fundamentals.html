Lesson 9.4: PyTorch Fundamentals

From Neurons to Networks

A neural network is a composition of parameterised functions. Each layer transforms its input into a new representation, and by stacking many layers the network can approximate arbitrarily complex functions — a result formalised as the Universal Approximation Theorem.

The perceptron, proposed by Frank Rosenblatt in 1957, is the atomic unit. It computes a weighted sum of its inputs and passes the result through an activation function:

y = f(w₁x₁ + w₂x₂ + … + wₙxₙ + b) = f(w·x + b)

where w are learnable weights, b is a learnable bias, and f is a non-linear activation function. Without a non-linearity, a stack of linear layers collapses to a single linear transformation — no matter how deep.

Activation Functions

FunctionFormulaRangeUse case
Sigmoid1 / (1 + e⁻ˣ)(0, 1)Binary output layer
Tanh(eˣ − e⁻ˣ) / (eˣ + e⁻ˣ)(−1, 1)Hidden layers (older nets)
ReLUmax(0, x)[0, ∞)Hidden layers — default choice
Leaky ReLUmax(0.01x, x)(−∞, ∞)Avoids dying ReLU problem
Softmaxeˣⁱ / Σeˣʲ(0, 1), sums to 1Multi-class output layer
ReLU is preferred in hidden layers because it does not saturate for positive inputs (unlike sigmoid/tanh), which mitigates the vanishing gradient problem and speeds up training dramatically.

PyTorch Fundamentals

import torch
import torch.nn as nn
import torch.optim as optim

# --- 1. Tensors ---
x = torch.tensor([[1.0, 2.0, 3.0]])   # shape (1, 3)
w = torch.randn(3, 2, requires_grad=True)
b = torch.zeros(2, requires_grad=True)

# Matrix multiplication + bias
out = x @ w + b   # shape (1, 2)

# --- 2. Define a model using nn.Module ---
class MLP(nn.Module):
    def __init__(self, input_dim, hidden_dim, output_dim):
        super().__init__()
        self.network = nn.Sequential(
            nn.Linear(input_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, output_dim)
        )

    def forward(self, x):
        return self.network(x)

model = MLP(input_dim=10, hidden_dim=64, output_dim=1)
print(model)

# --- 3. Training loop ---
criterion = nn.MSELoss()
optimiser = optim.Adam(model.parameters(), lr=1e-3)

# Dummy data
X_train = torch.randn(100, 10)
y_train = torch.randn(100, 1)

for epoch in range(200):
    model.train()
    optimiser.zero_grad()           # reset gradients
    predictions = model(X_train)    # forward pass
    loss = criterion(predictions, y_train)
    loss.backward()                 # backpropagation
    optimiser.step()                # update weights

    if (epoch + 1) % 50 == 0:
        print(f"Epoch {epoch+1}: Loss = {loss.item():.4f}")

Understanding Backpropagation

Backpropagation is the algorithm that computes gradients efficiently by applying the chain rule backwards through the computation graph. PyTorch builds this graph dynamically during the forward pass via autograd.

# PyTorch autograd in action
x = torch.tensor(3.0, requires_grad=True)
y = x ** 2 + 2 * x + 1   # y = x² + 2x + 1

y.backward()   # compute dy/dx
print(x.grad)  # dy/dx = 2x + 2 = 8.0 ✓

When you call loss.backward() on the final scalar loss, PyTorch traverses the computation graph in reverse and accumulates gradients into the .grad attribute of every leaf tensor that has requires_grad=True.
