Lesson 0.4: Calculus & Gradients

Why Calculus for ML?

Training any ML model reduces to minimising a loss function L(θ) over parameters θ. The gradient ∇L tells us the direction and magnitude of steepest increase — we step opposite to it. This is gradient descent, and it underlies every training algorithm from linear regression to GPT-4.

You do not need to derive every gradient by hand — PyTorch's autograd does it automatically. But you must understand what a gradient is, why the chain rule works, and what it means when a gradient vanishes or explodes.

Derivatives

The derivative f′(x) is the instantaneous rate of change — the slope of the tangent line at x:

f′(x) = limh→0 [f(x+h) − f(x)] / h
import numpy as np

def numerical_deriv(f, x, h=1e-5):
    """Central difference approximation — more accurate than forward diff."""
    return (f(x + h) - f(x - h)) / (2 * h)

f = lambda x: x**3 - 2*x**2 + x
print(numerical_deriv(f, 2.0))   # 3x²-4x+1 at x=2: 12-8+1 = 5.0
print(numerical_deriv(f, 0.5))   # 3(0.25)-4(0.5)+1 = 0.75-2+1 = -0.25

Partial Derivatives and the Gradient

For f(x₁, x₂, …, xₙ), the partial derivative ∂f/∂xᵢ measures how f changes as xᵢ varies while all other variables are held fixed. The gradient ∇f = [∂f/∂x₁, …, ∂f/∂xₙ] stacks all partial derivatives into a vector pointing in the direction of steepest increase.

def gradient_numerical(f, x, h=1e-5):
    """Gradient of f at vector x via central differences."""
    grad = np.zeros_like(x, dtype=float)
    for i in range(len(x)):
        xp, xm = x.copy(), x.copy()
        xp[i] += h; xm[i] -= h
        grad[i] = (f(xp) - f(xm)) / (2*h)
    return grad

# f(x,y) = x² + 2y² ; gradient = [2x, 4y]
f = lambda v: v[0]**2 + 2*v[1]**2
x = np.array([3.0, 1.0])
grad = gradient_numerical(f, x)
print(grad)  # [6.0, 4.0]  (exact: [2·3, 4·1])

# A gradient descent step
lr = 0.1
x_new = x - lr * grad
print(x_new)  # [2.4, 0.6] — moved toward minimum at (0,0)

The Chain Rule

Neural networks are compositions of functions: L = f₃(f₂(f₁(x; θ₁); θ₂); θ₃). The chain rule computes ∂L/∂θᵢ by multiplying local derivatives backwards through the composition:

dL/dx = (dL/db)·(db/da)·(da/dx)
import numpy as np

x   = 2.0
# Forward pass — save intermediate values
a   = x ** 2           # a = x², da/dx = 2x = 4
b   = np.exp(a)        # b = e^a, db/da = e^a = e^4 ≈ 54.6
L   = (b - 100) ** 2  # L = (b-100)², dL/db = 2(b-100)

# Backward pass — chain rule
dL_db = 2 * (b - 100)
db_da = np.exp(a)
da_dx = 2 * x

dL_dx = dL_db * db_da * da_dx
print(f"dL/dx = {dL_dx:.2f}")

# Numerical verification
h = 1e-5
f_plus  = (np.exp((x+h)**2) - 100)**2
f_minus = (np.exp((x-h)**2) - 100)**2
print(f"Numerical: {(f_plus - f_minus)/(2*h):.2f}")

Automatic Differentiation (Autograd)

PyTorch builds a computation graph during the forward pass. Each operation records its inputs and the local derivative rule. loss.backward() traverses this graph in reverse, accumulating gradients via the chain rule into .grad attributes.

import torch

# Scalar example
x = torch.tensor(2.0, requires_grad=True)
y = torch.tensor(3.0, requires_grad=True)

z = x**2 * y + torch.sin(y)  # z = x²y + sin(y)
z.backward()

# Analytical: dz/dx = 2xy = 12; dz/dy = x² + cos(y) = 4 + cos(3)
print(f"dz/dx = {x.grad:.4f}")   # 12.0
print(f"dz/dy = {y.grad:.4f}")   # 3.0100

# Gradient of loss wrt all model parameters — same mechanism
import torch.nn as nn
model = nn.Linear(10, 1)
x_in  = torch.randn(32, 10)
y_out = torch.randn(32, 1)
loss  = nn.MSELoss()(model(x_in), y_out)
loss.backward()   # fills .grad for every parameter in model
for name, p in model.named_parameters():
    print(f"{name}: grad shape = {p.grad.shape}")

Vanishing and Exploding Gradients

Deep networks can suffer from gradients that shrink (vanish) or grow (explode) exponentially as they propagate backwards through many layers. This prevents early layers from learning effectively.

import torch
import torch.nn as nn

# Simulate gradient flow through 50 sigmoid layers
x = torch.randn(1, 100, requires_grad=True)
h = x
for _ in range(50):
    h = torch.sigmoid(h)   # sigmoid derivative max = 0.25 → shrinks gradient

loss = h.sum()
loss.backward()

print(f"Max gradient magnitude: {x.grad.abs().max().item():.2e}")
# Typically 1e-15 or smaller — effectively zero

# ReLU helps: derivative is 1 for positive inputs
x = torch.randn(1, 100, requires_grad=True)
h = x
for _ in range(50):
    h = torch.relu(h)

loss = h.sum()
loss.backward()
print(f"Max gradient (ReLU): {x.grad.abs().max().item():.4f}")
