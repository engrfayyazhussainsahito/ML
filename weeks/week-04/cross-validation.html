Lesson 4.2: Cross-Validation

Why Cross-Validation?

A single train/validation split gives a noisy estimate of generalisation error — the result depends heavily on which samples happened to land in each split. Cross-validation uses all data for both training and validation by rotating through k non-overlapping folds, then averaging the k scores. This gives a lower-variance, less biased estimate of true performance.

K-Fold Cross-Validation

from sklearn.model_selection import KFold, cross_val_score, cross_validate
from sklearn.ensemble import RandomForestClassifier
from sklearn.datasets import make_classification
import numpy as np

X, y = make_classification(n_samples=1000, n_features=20, random_state=42)
model = RandomForestClassifier(n_estimators=100, random_state=42)

# 5-fold CV
cv = KFold(n_splits=5, shuffle=True, random_state=42)
scores = cross_val_score(model, X, y, cv=cv, scoring='accuracy', n_jobs=-1)

print(f"Fold scores:  {scores.round(3)}")
print(f"Mean:         {scores.mean():.3f}")
print(f"Std:          {scores.std():.3f}")
print(f"95% CI:       [{scores.mean()-2*scores.std():.3f}, {scores.mean()+2*scores.std():.3f}]")

# Multiple metrics at once
results = cross_validate(model, X, y, cv=cv,
                         scoring=['accuracy','f1','roc_auc'], n_jobs=-1)
for metric, vals in results.items():
    if metric.startswith('test_'):
        print(f"{metric[5:]:12s}: {vals.mean():.3f} +/- {vals.std():.3f}")

Stratified K-Fold

For classification, use StratifiedKFold to preserve the class distribution in each fold. This is especially important for imbalanced datasets where random splits might produce folds with no minority class examples.

from sklearn.model_selection import StratifiedKFold

# Creates a StratifiedKFold automatically when cv=int for classifiers
scores_stratified = cross_val_score(model, X, y, cv=5,
                                    scoring='f1', n_jobs=-1)

# Manual stratified fold
skf = StratifiedKFold(n_splits=5, shuffle=True, random_state=42)
for fold, (train_idx, val_idx) in enumerate(skf.split(X, y)):
    X_tr, X_val = X[train_idx], X[val_idx]
    y_tr, y_val = y[train_idx], y[val_idx]
    # Verify class balance in each fold
    print(f"Fold {fold+1}: train +rate={y_tr.mean():.2f}, val +rate={y_val.mean():.2f}")

Nested Cross-Validation

If you use cross-validation both to select hyperparameters AND evaluate the model, you get an optimistically biased estimate — the outer CV is compromised by the inner selection. Nested CV uses an outer loop for evaluation and an inner loop for hyperparameter selection, giving an unbiased performance estimate.

from sklearn.model_selection import GridSearchCV, cross_val_score
from sklearn.ensemble import RandomForestClassifier
import numpy as np

# Inner CV: select best hyperparameters
param_grid = {'n_estimators': [50, 100, 200], 'max_depth': [3, 5, None]}
inner_cv = StratifiedKFold(n_splits=3, shuffle=True, random_state=1)
outer_cv = StratifiedKFold(n_splits=5, shuffle=True, random_state=2)

clf = GridSearchCV(RandomForestClassifier(random_state=42),
                   param_grid, cv=inner_cv, scoring='f1', n_jobs=-1)

# Outer CV: unbiased performance estimate
outer_scores = cross_val_score(clf, X, y, cv=outer_cv,
                               scoring='f1', n_jobs=-1)
print(f"Nested CV F1: {outer_scores.mean():.3f} +/- {outer_scores.std():.3f}")

# Compare to non-nested (optimistically biased)
clf_simple = GridSearchCV(RandomForestClassifier(random_state=42),
                          param_grid, cv=5, scoring='f1', n_jobs=-1)
clf_simple.fit(X, y)
print(f"Non-nested best CV F1: {clf_simple.best_score_:.3f}  (optimistic)")

Time Series Cross-Validation

For sequential data, random splitting causes leakage — future data is used to predict the past. Use TimeSeriesSplit which always trains on past data and validates on future data.

from sklearn.model_selection import TimeSeriesSplit
import numpy as np

X_ts = np.random.randn(1000, 5)
y_ts = np.random.randn(1000)

tscv = TimeSeriesSplit(n_splits=5)
for fold, (train_idx, val_idx) in enumerate(tscv.split(X_ts)):
    print(f"Fold {fold+1}: train=[{train_idx[0]}:{train_idx[-1]}], "
          f"val=[{val_idx[0]}:{val_idx[-1]}]")
# Each fold: training window grows, validation always in the future
