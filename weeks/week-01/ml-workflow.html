Lesson 1.3: The ML Workflow

The End-to-End Pipeline

A production ML project follows a repeatable workflow. Each stage has failure modes that propagate downstream — a bad problem framing or leaky train/test split corrupts every subsequent metric.

graph LR
  A[Problem framing] --> B[Data collection]
  B --> C[EDA and cleaning]
  C --> D[Feature engineering]
  D --> E[Modelling]
  E --> F[Evaluation]
  F --> G[Deployment]
  G --> H[Monitoring]
  H -->|drift detected| C

Problem Framing

Before writing any code, answer these questions: What exactly is the prediction target? What is the cost of each type of error? Is the target measurable and available at training time but not at inference time (leakage risk)? Is ML even the right tool, or would a rule-based system suffice?

Many failed ML projects stem from wrong problem formulations, not bad models. One extra day on framing saves weeks of wasted modelling effort.
# Frame the problem concretely
problem = {
    "task":       "binary classification",
    "target":     "customer churns within 30 days",
    "features":   ["usage_days", "support_tickets", "plan_type", "tenure"],
    "metric":     "F1-score (churn is rare; accuracy misleads)",
    "baseline":   "majority class: F1 ≈ 0 on minority class",
    "constraint": "prediction must be available 7 days before renewal"
}

Data Splitting

The test set must be held out completely and used only once. Using it iteratively inflates estimates through multiple comparison. The validation set is used to tune hyperparameters and compare model variants.

from sklearn.model_selection import train_test_split
import numpy as np

X = np.random.randn(10000, 20)
y = np.random.randint(0, 2, 10000)

# 70% train, 15% validation, 15% test
X_temp, X_test, y_temp, y_test = train_test_split(
    X, y, test_size=0.15, stratify=y, random_state=42)
X_train, X_val, y_train, y_val = train_test_split(
    X_temp, y_temp, test_size=0.15/0.85, stratify=y_temp, random_state=42)

print(f"Train: {len(X_train)}, Val: {len(X_val)}, Test: {len(X_test)}")

# For time series: NEVER shuffle — use chronological order
# train = data[:7000], val = data[7000:8500], test = data[8500:]

Establishing a Baseline

Always build the simplest possible model first. Every subsequent model must beat the baseline to justify its complexity cost.

from sklearn.dummy import DummyClassifier
from sklearn.linear_model import LogisticRegression
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.metrics import f1_score

# Baseline 1: always predict majority class
dummy = DummyClassifier(strategy='most_frequent')
dummy.fit(X_train, y_train)
print(f"Dummy F1: {f1_score(y_val, dummy.predict(X_val)):.3f}")

# Baseline 2: linear model with default settings
lr = make_pipeline(StandardScaler(), LogisticRegression(max_iter=1000))
lr.fit(X_train, y_train)
print(f"LogReg F1: {f1_score(y_val, lr.predict(X_val)):.3f}")

Iterative Improvement

from sklearn.ensemble import GradientBoostingClassifier, RandomForestClassifier
from sklearn.model_selection import cross_val_score

candidates = {
    "LogReg":  make_pipeline(StandardScaler(), LogisticRegression()),
    "RF":      RandomForestClassifier(n_estimators=100, random_state=42),
    "GBM":     GradientBoostingClassifier(n_estimators=200, random_state=42),
}

for name, model in candidates.items():
    scores = cross_val_score(model, X_train, y_train,
                             cv=5, scoring='f1', n_jobs=-1)
    print(f"{name}: {scores.mean():.3f} +/- {scores.std():.3f}")

Final Evaluation with Confidence Intervals

from sklearn.metrics import classification_report
from sklearn.utils import resample
import numpy as np

# Final fit on train+val, evaluate on test — exactly once
best_model.fit(np.vstack([X_train, X_val]), np.concatenate([y_train, y_val]))
y_pred = best_model.predict(X_test)
print(classification_report(y_test, y_pred))

# Bootstrap 95% CI for F1
f1s = [f1_score(y_test[idx := resample(range(len(y_test)))], y_pred[idx])
       for _ in range(1000)]
lo, hi = np.percentile(f1s, [2.5, 97.5])
print(f"F1 95% CI: [{lo:.3f}, {hi:.3f}]")
