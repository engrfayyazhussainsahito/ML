Week 10 · Convolutional Neural Networks

Lesson 10.1: Convolution & Pooling

What is a Convolutional Layer?

A convolutional layer applies a set of learnable filters to an input. Each filter slides across the spatial dimensions, computing dot products at each position to produce a feature map. This operation is translation equivariant — if a pattern moves in the input, the corresponding activation moves by the same amount in the output.

Key parameters: kernel size (spatial extent of the filter), stride (step size), padding (zeros added around edges), number of filters (depth of output).

Convolution in PyTorch

import torch
import torch.nn as nn

# 2D convolution: 3-channel input (RGB) → 16 feature maps
conv = nn.Conv2d(
    in_channels=3,    # RGB
    out_channels=16,  # 16 filters
    kernel_size=3,    # 3×3 filter
    stride=1,
    padding=1         # 'same' padding — output same size as input
)

# Input: batch of 8 RGB images, 32×32 pixels
x = torch.randn(8, 3, 32, 32)
out = conv(x)
print(out.shape)   # (8, 16, 32, 32)

# Parameters: 16 filters × (3 channels × 3×3 weights + 1 bias) = 448
print(sum(p.numel() for p in conv.parameters()))  # 448

Pooling

Pooling layers reduce spatial dimensions by summarising regions, introducing translation invariance and reducing computation:

# Max pooling: take the maximum in each 2×2 window
pool = nn.MaxPool2d(kernel_size=2, stride=2)
out_pooled = pool(out)
print(out_pooled.shape)   # (8, 16, 16, 16) — halved spatial dims

# Average pooling
avg_pool = nn.AdaptiveAvgPool2d((1, 1))   # global average pooling
gap = avg_pool(out)
print(gap.shape)           # (8, 16, 1, 1) — one value per feature map

A Complete CNN for Image Classification

class ConvNet(nn.Module):
    def __init__(self, num_classes=10):
        super().__init__()
        self.features = nn.Sequential(
            # Block 1
            nn.Conv2d(3, 32, 3, padding=1), nn.BatchNorm2d(32), nn.ReLU(),
            nn.MaxPool2d(2),   # 32×32 → 16×16

            # Block 2
            nn.Conv2d(32, 64, 3, padding=1), nn.BatchNorm2d(64), nn.ReLU(),
            nn.MaxPool2d(2),   # 16×16 → 8×8

            # Block 3
            nn.Conv2d(64, 128, 3, padding=1), nn.BatchNorm2d(128), nn.ReLU(),
            nn.AdaptiveAvgPool2d((1, 1))   # → 1×1
        )
        self.classifier = nn.Sequential(
            nn.Flatten(),
            nn.Linear(128, 256),
            nn.ReLU(),
            nn.Dropout(0.5),
            nn.Linear(256, num_classes)
        )

    def forward(self, x):
        return self.classifier(self.features(x))

model = ConvNet(num_classes=10)
x = torch.randn(4, 3, 32, 32)
print(model(x).shape)   # (4, 10)
total_params = sum(p.numel() for p in model.parameters())
print(f"Parameters: {total_params:,}")

Batch Normalisation

Batch normalisation normalises layer inputs across the mini-batch, greatly stabilising training and allowing higher learning rates:

# BN normalises: y = γ * (x - μ_batch) / σ_batch + β
# γ and β are learnable parameters
bn = nn.BatchNorm2d(64)   # one scale/shift per channel
